# 🖥️ Sistema de Chamados TI - MVP

## Objetivo
Desenvolver uma interface funcional para abertura e resolução de chamados de suporte de TI, permitindo que usuários registrem solicitações e administradores gerenciem o atendimento.

## Tecnologias
- HTML5
- CSS3
- JavaScript (Vanilla)
- Node.js + Express
- SQLite
- JWT para autenticação

## Metodologia de desenvolvimento
- **Metodologia:** Kanban
- **Por que escolhemos:** Permite fluxo contínuo adaptável, ideal para um MVP com mudança frequentes de prioridade. O limite de WIP garante foco e qualidade nas entregas.

## Como vamos trabalhar
- **Fluxo:** Backlog → A Fazer → Em Andamento → Revisão → Concluído
- **Limite de WIP:** Máximo de 2 tarefas por pessoa
- **Rotina de acompanhamento:** Reunião semanal durante a duração de cada aula
- **Ferramenta de tarefas:** GitHub Projects

## Definição de pronto (DoD)
- Funciona no navegador sem erros visíveis
- Sem erros no console
- Estrutura HTML organizada/semântica
- CSS aplicado conforme padrão combinado
- JS implementado conforme o esperado no MVP
- Versionado no repositório com commit(s) coerente(s)
- Atualizado no quadro de tarefas
- Código revisado por pelo menos um colega

## Como executar
1. Clone o repositório
2. Instale as dependências: `cd backend && npm install`
3. Configure o arquivo `.env` com as variáveis necessárias
4. Inicie o servidor: `npm start`
5. Acesse `http://localhost:3000`
6. Login: admin/admin ou user/user
